## Recorders

Append-only JSON. One object per observation. A later poll of the same source point keeps the first file, including when only `observed_at` changed. A different value at that point is refused, and the rest of the run is still written. Failures go under `observation-failures/` and are not bars. A Binance 418 aborts the run. Other spot errors become failure records for both spread and depth. Symbols must match `^[A-Z0-9]{1,20}$`.

| Series | Family | Cadence | Provider |
|---|---|---|---|
| `btc_dominance` | `market_regime` | daily is enough | CoinGecko `/api/v3/global` |
| `stablecoin_supply` | `market_regime` | daily is enough | DefiLlama `stablecoincharts/all` (its `date` is a numeric string) |
| `funding` | `derivatives_positioning` | hourly | Binance public `fapi` `premiumIndex` |
| `open_interest` | `derivatives_positioning` | hourly | Binance public `fapi` `openInterest`, unit `base_asset` |
| `spread`, `depth` | `execution_liquidity` | each scan | Spot depth on `data-api.binance.vision` |

Open interest is the raw Binance base-asset quantity. Notional open interest is not computed here; a later milestone derives it from this quantity and a point-in-time price. Depth inside the book uses `recorders.depth_band_bps` from the policy file. The loaded value is 200, which is ±2% of mid. A missing or non-integer band fails closed.

Each file stores series, family, provider, source timestamp when the provider sends one, `observed_at`, symbol when the series has one, values, units, `schema_version`, and `collection_status`. Staleness is `observed_at`, not the schedule time.

`rate(1 hour)` invokes `cip.handlers.recorders.record` in dev. The function reads `DATA_BUCKET` and writes `observations/` and `observation-failures/` in that bucket for `BTCUSDT` and `ETHUSDT`. A later poll of an unchanged daily source point keeps the first object. Spread and depth have no provider timestamp, so each cycle appends a new pair. `python -m cip.recorders run --output DIR` writes the same layout on a local disk. Futures traffic uses `https://fapi.binance.com`. From us-east-1 that host can return 451; the recorder stores the failure and does not invent a bar. A Binance 418 aborts the invocation before anything from that cycle is stored.
