# DCA benchmark Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command replays a BTC dollar-cost-averaging book and a BTC/ETH book on the same contribution calendar and prints their portfolio metrics as JSON.

**Architecture:** `contribution_schedule` and `allocate` turn the policy amounts into dated cent legs. `simulate` fills those legs at each day's open and marks holdings at the close. `metrics` computes time-weighted return, XIRR, Sharpe, Sortino, drawdown, Calmar, and the mixed book's excess, beta, and alpha. The CLI loads only `BTCUSDT` and `ETHUSDT` parquet months.

**Tech Stack:** Python 3.13, Decimal, pytest, hypothesis, pyarrow (history group, already installed for `read_month`), ruff, mypy.

## Global Constraints

- Spec: `docs/plans/2026-10-03-m2-backtest-design.md`. Follow it.
- Do not apply `contribution_split`. Do not read the kill thresholds. Do not add scoring, eligibility, equal-weight, random, spread, slippage, S3, Terraform, or a download.
- Do not check the three backtest boxes in `docs/plans/2026-10-03-roadmap.md`.
- `BacktestError` subclasses `CipError`. The CLI exits 1 for `BacktestError` and `PolicyError`, and prints `error: …` to stderr.
- Amounts and the fee rate enter as `Decimal(str(...))` from the loaded policy. Legs are cents, `ROUND_HALF_UP`, residual on the alphabetically last symbol.
- Fills use that day's open. Quantity is `notional * (1 - taker_fee_rate) / open`. Cash stays zero.
- Fewer than two daily returns raises `BacktestError`. Undefined Sharpe, Sortino, Calmar, beta, and alpha are JSON `null`. The command still exits 0.
- XIRR Newton starts at `0.1`, cap 100, stop when the absolute step is below `1e-12`. Day count is `(date - first).days / 365`.
- Coverage stays at 100% branch coverage. No test calls the network. Ruff line length 100. Mypy strict.
- Do not call `load_bars`.
